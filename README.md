# 生物会考冲A

给湖南（娄底）八年级学生用的**生物学会考离线刷题程序**。按人教版（2024）新教材和湖南省现行考试结构编写，电脑和手机都能用，不需要联网，不需要安装。老师也可以用它组卷、打印和课堂投屏。

| 文件 | 用途 |
| --- | --- |
| `dist/生物会考冲A.html` | 程序本体。一个文件就是全部内容，双击打开即可使用 |
| `dist/开卷速查手册.pdf` | 22章速查手册加“考前必看”，A4，共45页，可以直接打印 |

## 怎么用

**电脑**：下载 `dist/生物会考冲A.html`，双击用浏览器打开。推荐 Chrome、Edge 或 360 极速模式。做题记录保存在这台电脑的浏览器里，换浏览器或清理浏览器数据会丢失，可以在“我的与设置”里导出备份。

**安卓手机**：把文件发到手机上（如通过 QQ 或微信“文件传输助手”），在文件管理里选择“用其他应用打开”，用 Chrome、QQ 浏览器、夸克或系统自带浏览器打开。不要直接在微信里打开，微信内置浏览器可能无法运行，也保存不了进度。

**苹果手机**：用“文件”App 可以打开浏览，但有的 iOS 版本不能可靠地保存做题进度。iPhone 用户建议同时在电脑上使用，或定期导出备份。

**多个学生共用一台设备**：在“我的与设置”里新建学生档案，每个人的记录分开保存。

## 学生能做什么

- **每日一练**：每天10道题，优先安排到期的错题，其余从最薄弱的章节里挑。
- **章节练习**：按课本22章顺序刷题，每题做完立刻看解析。
- **专项突破**：非选择题按识图、实验探究、资料分析分类练；“识图训练”把64幅示意图上的每个结构名称和功能都考一遍。
- **全真模考**：按湖南试卷结构组卷（25道单选每题2分，非选择题5～7道共50分，60分钟），限时作答。交卷后自动判分，简答题对照参考答案自评，给出100分制成绩、A～D等第，以及按章节排列的失分分布。
- **错题本**：做错的题自动收进来，按间隔复习安排重做，隔天连续答对3次才算掌握。
- **开卷速查手册**：每章的必考结论、对比表格、实验步骤和易错清单，附带标好名称的示意图，可以按章或整本打印。
- **搜索**：按关键词查题目和手册内容。

## 老师能做什么

- **组卷**：按章节、题型、难度和分值出题，有“全真模拟”“单元小测”“课堂小练”三种预设。每道题都能换一道或删掉，可以打印试卷、打印答案与解析，或保存起来下次再用。同一份卷子打印出来的选项顺序是固定的。
- **课堂投屏**：大字号逐题讲评，先遮住答案，再一键显示。
- **导入自己的题目**：在“我的与设置”里，把 Excel 中的题目复制粘贴进来即可。每行一题，各列依次是：

  `章节　题型（单选/判断）　题干　A　B　C　D　答案　解析`

  判断题的 A～D 列留空，答案填“对”或“错”。导入的题只保存在这台设备上。

## 内容依据和说明

- **知识范围**：《义务教育生物学课程标准（2022年版）》，人教版《生物学》七年级上册至八年级下册（2024年版新教材）。章节名称和术语按新教材，如“藻类”“刺胞动物”“薄壁组织”“免疫规划”。
- **试卷结构**：湖南省2025年修订的初中学业水平考试试卷结构（2026年起执行），生物学为开卷考试，60分钟，满分100分。
- **等第划分**：程序里的A≥80、B 70～79、C 60～69、D<60，参考的是娄底近年的中考政策。每年的具体办法，以及考场允许携带哪些资料，**以当年省、市教育部门的正式文件为准**。
- **题目来源**：全部题目、解析、示意图和手册都是原创编写的。命题参照湖南各地会考常见的题型和设问方式，但不是任何一年的真题，也没有照搬市面上的教辅。做题时如果发现错误，欢迎指出。
- **隐私**：程序完全离线运行，不联网，不收集任何信息。

## 开发

程序是原生 JavaScript，不依赖任何第三方库。源文件按顺序拼接，打包成一个内联了样式、题库和代码的 HTML 文件。

```
src/app/        程序代码（core、figkit、store、engine、exam、views、main）
src/styles.css  样式（浅色、深色、打印）
data/chapters.js       教材章节和考试结构
data/questions/*.js    各章题库，一章一个文件
data/figures/*.js      示意图（SVG，由 figkit 绘制）
data/handbook/*.js     开卷速查手册和“考前必看”
tools/          构建、校验、示意图预览、手册 PDF 导出
tests/          浏览器冒烟测试、组卷规则测试
```

常用命令（需要 Node.js 18 或更高版本；浏览器测试和 PDF 导出还需要 Playwright）：

```sh
node tools/validate.mjs          # 校验题库：答案、选项、图片引用、重复题干等
node tools/build.mjs             # 生成 dist/生物会考冲A.html 和 dist/artifact.html
node tools/handbook-pdf.mjs      # 生成 dist/开卷速查手册.pdf
node tests/exam-compose.mjs      # 组卷规则测试（单选按册配额、非选择题凑满50分且各册都有）
node tests/smoke.mjs [截图目录]   # 在手机和电脑尺寸下点一遍主要页面
node tools/figpreview.mjs <目录> [图名]   # 把示意图渲染成 PNG，逐张检查
```

**题目格式**：正确选项写在第一个（`a: 0`），做题时选项会自动打乱；解析里不要写“A项”“选B”这类字母。非选择题由若干小题组成，小题类型可以是单选、判断、填空或简答，每道大题总分为6、8、10或12分，这样组卷时才能凑满50分。具体写法可以参照 `data/questions/` 里已有的文件。
