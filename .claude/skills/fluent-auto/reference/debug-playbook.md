# 调试手册:症状 → 原因 → 处理

"自动"表示 `run` 会自己处理,或者 Claude 可以直接修。"问用户"表示涉及物理设置,必须先确认。

## A. transcript 里的错误(SETUP_ERROR)

| 症状 | 常见原因 | 处理 |
|---|---|---|
| `invalid command` / `ambiguous` / `is not a valid` | TUI 路径或关键字写错(版本差异) | 自动:按 tui-notes.md 修模板 |
| 回显的提示和给的答案对不上(比如在 `Use profile?` 处填了数值) | 提示的个数或顺序和模板不一致 | 自动:数清实际的提示数,修改模板 |
| `no such zone` / `not found` | zone 名不对 | 自动:用 `inspect` 的 zone 名修规格;对应关系不明确时问用户 |
| `cannot open file` | 路径不存在、含中文,或者目录没建 | 自动:检查路径 |
| 报告值解析失败 | 报告命令执行了,但输出格式和解析规则不一致 | 自动:看 transcript 里 `@@FA REPORT` 块的实际输出,修改 parser.report_value 或换一种 report kind |

## B. 发散(DIVERGED)

| 症状 | 可能原因 | 自动阶梯 / 建议 |
|---|---|---|
| 前几十步就 `Divergence detected in AMG solver` | 网格单位错(mm 当成 m)、边界条件数值错、网格质量差、初值差 | 先自动走阶梯。如果前两级都很快就发散,优先怀疑**单位和边界条件**:让用户核对 `inspect` 显示的计算域尺寸和 BC 数值 |
| 残差先下降,后来爆掉 | 欠松弛太大,或者二阶切换过早 | 第 1 级:欠松弛和 Courant 数降到 0.7 倍,一阶预热加倍 |
| 换成 SIMPLE 和保守欠松弛仍然发散 | 物理或网格问题 | 第 3 级:全程一阶,换一种初始化 |
| 第 3 级以后仍然发散 | 网格(高度扭曲、负体积)、计算域或边界条件 | **问用户**:报告网格最小正交质量和最大长宽比;建议修网格(最小正交质量最好 >0.1,至少 >0.01) |
| `floating point exception` | 同上,或者材料物性写错(比如黏度为 0) | 同上,并核对 material |

## C. 不收敛(NOT_CONVERGED)

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 残差一直在下降,只是步数不够 | 正常 | 自动从结果续算 |
| 残差停在 1e-3 ~ 1e-4 不动,监视量稳定 | 网格局部质量差,或者轻微的非定常 | 自动:满足工程收敛条件时接受,报告里会注明 |
| 残差周期性振荡,监视量也振荡 | **流动本身是非定常的**(涡脱落、分离) | 自动小幅降低欠松弛。如果持续振荡,**问用户**是否改瞬态计算(第一版没有做瞬态的自动调试) |
| `reversed flow in N faces on pressure-outlet` | 出口离回流区太近 | **问用户**:建议延长出口段,或者接受(看回流面数是否持续减少) |
| `turbulent viscosity limited to viscosity ratio` | 初值或局部网格差 | 自动:多算一些步数通常会消失;一直出现时检查网格 |
| 质量不平衡大 | 没算够,或者出口有回流 | 自动续算 |

## D. 已收敛但与参考值不符(REF_MISMATCH)

自动部分:确认使用二阶格式,再把残差标准收紧到 1e-5 续算。仍然不符时停下来**问用户**,按下面顺序排查:

1. **参考值本身的定义和计算值是否一致**:静压还是总压;面积平均还是质量平均;表压还是绝压(操作压力);流量的正负号(可以用 `abs`)。
2. **单位和边界条件数值**:速度、流量、物性、网格单位。
3. **近壁处理**:用 `{"kind": "facet-avg", "field": "y-plus", "surfaces": ["wall"]}` 查看 y+。k-ω SST 在壁面解析时要求 y+ ≈ 1;壁面函数要求 30 < y+ < 300。
4. **网格无关性**:在关键区域加密网格(需要用户重新出网格),比较两套网格的结果。
5. **湍流模型**:分离流和旋转流可以试 k-ω SST 和 realizable k-ε;层流和湍流的判断要看雷诺数。
6. **入口条件**:入口速度剖面是否需要充分发展;湍流强度。
7. **计算域**:入口和出口段长度是否足够。

每一项都需要用户确认后再改。改完以后作为新的一轮 `run`,不要在原来的运行目录里混算。

## E. 环境问题(ENV_ERROR / TIMEOUT)

| 症状 | 处理 |
|---|---|
| 没有 transcript、launcher.log 里 `CMD` 之后什么都没有 | fluent.exe 路径错。检查 `fluent.exe` 字段或环境变量 `AWP_ROOT221` |
| license 相关报错 | 告诉用户检查许可证服务器(ANSYS License Manager)和网络 |
| transcript 中途截断,没有结尾标记 | Fluent 崩溃或内存不足:减少核数或网格规模,查看 launcher.log |
| 超时 | 增大 `timeout_min`、增加 `processes`,或者减小单次 `iterations`(续算会接上) |
